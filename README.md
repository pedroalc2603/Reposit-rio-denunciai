📢 Aplicativo de Denúncias
📌 Sobre o Projeto

O Aplicativo de Denúncias é uma plataforma desenvolvida com o objetivo de facilitar o registro e o acompanhamento de denúncias, permitindo que os cidadãos comuniquem situações irregulares, problemas ou ocorrências de forma simples, rápida e segura.

A aplicação busca promover a participação da sociedade, incentivando a transparência, a responsabilidade e a colaboração entre cidadãos e órgãos responsáveis.

🎯 Objetivos
Facilitar o registro de denúncias.
Permitir o envio de fotos e outras evidências.
Garantir a confidencialidade das informações dos denunciantes.
Possibilitar o acompanhamento do status das denúncias.
Organizar e centralizar as ocorrências registradas.
Contribuir para a resolução de problemas na comunidade.
⚙️ Funcionalidades
Cadastro de usuários: criação de contas para acessar a plataforma.
Login: autenticação segura dos usuários.
Registrar denúncia: formulário para descrever a ocorrência.
Anexar evidências: possibilidade de adicionar imagens e documentos.
Localização: identificação do local onde ocorreu o problema.
Acompanhamento: consulta ao andamento das denúncias.
Histórico: visualização das denúncias realizadas.
Painel administrativo: gerenciamento e análise das denúncias recebidas.

🔐 Segurança e Privacidade

A aplicação busca proteger os dados dos usuários e garantir a confidencialidade das denúncias.

Entre as medidas previstas estão:

Proteção dos dados pessoais.
Controle de acesso às informações.
Armazenamento seguro das denúncias.
Possibilidade de denúncia anônima, quando aplicável.
Restrição do acesso às informações sensíveis.
👥 Público-Alvo

O aplicativo é destinado a cidadãos que desejam comunicar irregularidades, situações de risco ou problemas que necessitam de atenção das autoridades ou dos responsáveis.

🌱 Impacto Social

O projeto busca incentivar a cidadania ativa, facilitar a comunicação entre população e instituições responsáveis e contribuir para a construção de uma sociedade mais participativa, transparente e segura.
